# Post-Capitalist Transition

A working framework for civilizational change. Derived from a 2026 conversation, kept in a public repo so it's easy to share with friends I want to think about it with.

## What this is

A long-form artifact mapping the structural prerequisites for a transition away from extractive growth-optimization toward a system that treats human flourishing and ecological repair as foundational. Not a policy proposal. Not an academic paper. A values-clarification document I take seriously and want to keep thinking about with people I trust.

## What this is not

- A finished position. Held with conviction, but read as v0.X, not v1.0.
- A claim to expertise. One synthesis among many possible ones.
- A debate prompt. Pushback is welcome; arguing-to-win is not the mode.

## How to engage

- **Disagreements, additions, clarifying questions:** open an issue. I'd rather think with people than be argued at.
- **Concrete edits you'd want to see:** open a pull request with the change and your reasoning. I'll read every PR carefully even if I don't merge it.
- **Side conversations:** the friends I've shared this with directly know how to reach me.

## Status

Working document. Will revise as my thinking evolves. Linked from my own values doc as the source of the civilizational layer of values I hold.
